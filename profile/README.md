# DFBB Dance Crew

DFBB is a Boston-based dance crew sharing a love of dance and East Asian pop culture. We focus on dance covers and group performances, with projects spanning K-pop, C-pop, and beyond. We value the effort that goes into each project and the friendships that grow along the way.
